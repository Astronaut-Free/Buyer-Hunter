# A6 Stop Conditions

## 1. 立即停止联系

```text
UNSUBSCRIBE
SUPPRESSION_MATCH
MANUAL_STOP
```

## 2. 阻断自动推进

```text
A5_BLOCKED
OPPORTUNITY_UNRESOLVED
DEPENDENCY_BLOCKED
```

## 3. 强制人工

```text
COMPLAINT
PRICE_FORMAL
CONTRACT
PAYMENT_TERMS_FORMAL
EXCLUSIVE
HIGH_VALUE_ACCOUNT
GOVERNMENT_OR_MAJOR_INSTITUTION
```

## 4. 等待

```text
WAITING_BUYER_REPLY
WAITING_SELLER_DATA
WAITING_APPROVAL
WAITING_EVIDENCE
WAITING_SAMPLE_STATE
WAITING_QUOTE_STATE
```

## 5. 完成

```text
WON
LOST
STOPPED
NURTURE
```

所有 Stop / Wait / Complete 都必须保存原因与 evidence refs。
