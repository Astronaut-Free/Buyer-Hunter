# A2 Examples

## 正例：贵州抹茶 → 美国原料进口商

输入：目标美国，产品抹茶粉，Buyer Type 为食品原料进口商 / 分销商。

正确链路：

```text
贸易数据发现候选公司
→ 官网验证经营茶粉 / 饮品原料
→ Buyer Fit
→ Apollo 类联系人 Adapter 找采购角色
→ READY
→ 证据化 Email Draft
→ Approval
```

## 反例：先找到采购经理

输入只有姓名、职位与邮箱，没有公司产品、贸易或市场证据。

正确处理：

```text
MORE_EVIDENCE
```

禁止写“该公司有明确抹茶采购需求”。

## 边界：贸易数据为空

如果目标行业贸易数据覆盖不足，可以使用官网、展会或商协会公开证据建立 Buyer Fit。

禁止把“没有贸易记录”直接等于“不值得开发”。
