# A2 Validation Checklist

运行结束前逐项检查：

- [ ] Target Definition 已结构化。
- [ ] Buyer Company 先于联系人 enrichment。
- [ ] Buyer Fit 有 evidence refs。
- [ ] Why Now 若缺近期证据已明确标记。
- [ ] 联系人与 Buyer Company 已可靠绑定。
- [ ] Outreach Readiness 为三态之一。
- [ ] A5 BLOCKED / suppression / unsubscribe 已优先处理。
- [ ] 首次外发进入 Human Gate。
- [ ] Email 副作用有 idempotency key。
- [ ] Buyer Reply 已 handoff A6。
- [ ] 没有因为候选不足扩张全部社媒渠道。
- [ ] Result Envelope 可被 Agent 调度。
