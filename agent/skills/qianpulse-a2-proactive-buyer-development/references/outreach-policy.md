# A2 Outreach Policy

## 1. 目标

外联内容以真实 Buyer Evidence 为起点，保持短、具体、可回复。

## 2. 信息结构

```text
为什么联系你
→ 与对方业务的相关性
→ 我们能提供什么
→ 一个低摩擦 CTA
```

## 3. Claims Guard

所有会影响商业判断的事实必须存在证据或卖家授权信息。

禁止：

- 虚构对方当前采购需求。
- 虚构近期采购计划。
- 虚构客户案例。
- 未授权价格。
- 未验证认证。
- 未确认交期。
- 独家代理承诺。
- 付款与合同承诺。

## 4. Human Gate

一期所有首次外发 Email 均需人工审批。

后续如果开放低风险 Auto Send，也必须由企业级策略显式开启。

## 5. 个性化最低要求

邮件至少引用一项：

- 对方产品。
- 对方贸易行为。
- 对方市场定位。
- 对方公开业务场景。

若没有可引用 Buyer Evidence，返回 `MORE_EVIDENCE`。
