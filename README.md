# 买家猎手（方案文档）

主投贵客松赛道三。产品定位为面向贵州卖家的 **海外买家需求情报聚合与智能撮合平台**。平台抓取、清洗和验证海外采购需求，卖家作为平台用户从中寻找合适买家；抹茶和蓝莓只是 36 小时 Demo 的两个检索/匹配样例。

商业模式：卖家购买会员，免费态预览需求摘要；会员解锁完整买家需求、采购入口和可验证的公开 B2B 联系方式，再由卖家自主跟进成交。Demo 只实现预置会员、服务端权限和解锁额度，不接真实支付。

## 36 小时 Demo 主链

```text
卖家私有匹配条件（不公开展示商品）
→ 2–3 个公开来源
→ 30–50 条候选信号
→ 清洗 / 实体去重 / 四维验真
→ 产品能力匹配
→ Top 5 买家
→ 免费需求预览
→ 会员解锁 Evidence / Why Now / Gap / Next Action
→ 获取采购入口/公开 B2B 联系方式并自主跟进
```

平台当前不是店铺、商品展示商城或双边交易市场。合同、支付、订单、报关、物流与履约不进入 36 小时开发。
