# 买家猎手（Buyer Hunter）

主投贵客松赛道三，同时覆盖赛道二的产业供需连接能力。产品定位为面向贵州卖家的 **海外采购机会决策系统**：持续抓取、清洗和验证海外买方需求，再结合卖方私有能力，判断今天最值得追的采购机会。

商业模式：卖家购买决策会员，获得每日 Top 5、为什么现在、供需匹配、市场准入、风险、Gap 和下一步行动。公司身份可以公开展示；采购入口与公开 B2B 联系方式属于独立的 Lead Access 执行资源。Demo 只模拟会员权限与额度，不接真实支付。

## 36 小时 Demo 主链

```text
卖方私有能力档案
→ 公开信号采集
→ 清洗 / 实体去重 / 四维验真
→ 采购窗口判断
→ 供需匹配 / 市场准入 / 风险
→ 今日 Top 5 机会决策
→ 为什么现在 / Gap / 下一步行动
→ 需要执行时再解锁采购入口与公开商务渠道
```

平台当前不是店铺、商品展示商城、买家名录或双边交易市场。合同、支付、订单、报关、物流与履约不进入 36 小时开发。
