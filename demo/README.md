# 买家猎手交互 Demo

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

访问 `http://127.0.0.1:4173/`。

## 演示主链

1. 首页点击任一 Top 5 机会。
2. 免费态查看受限身份、真实性、供需匹配、证据时间线和 Gap。
3. 点击“查看会员权益”，再点击“切换至演示会员”。
4. 使用 1 次额度解锁当前买家。
5. 查看完整公司、模拟采购入口和公开商务邮箱。
6. 记录跟进，并切换为洽谈中、已成交或未成交。

所有公司、邮箱和采购 URL 均为 Demo 模拟数据，不代表真实联系方式；本 Demo 不接支付、不自动外联、不处理合同或履约。

## 验证
