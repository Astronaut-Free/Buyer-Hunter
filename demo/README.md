# 买家猎手机会决策 Demo

## 本地运行

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

访问 `http://127.0.0.1:4173/`。

## 演示主链

1. 首页查看系统排序的“今日 Top 5 决策”。
2. 点击机会，免费查看买家身份、需求、决策摘要与“为什么现在”。
3. 点击“查看决策会员”，切换至演示会员。
4. 查看完整匹配矩阵、证据链、准入风险、Gap 与下一步动作。
5. 确定执行后，使用 1 次 Lead Access 额度解锁公开采购入口与商务邮箱。
6. 记录跟进，并切换为洽谈中、已成交或未成交。

所有公司、邮箱和采购 URL 均为 Demo 模拟数据，不代表真实联系方式；本 Demo 不接支付、不自动外联、不处理合同或履约。
