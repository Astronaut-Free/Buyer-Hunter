## 3. 样本反推的字段分组

本轮最终记录实际登记 40 个字段路径，按以下 8 组组织：

| 字段组 | 已落字段 | 本轮价值 |
|---|---|---|
| `source` | code、url、record_kind、data_mode | 区分 RFQ、目录、历史采购、采购入口 |
| `buyer` | name_raw、country_raw、country_code、supplier_name_raw | 买家实体及 USA 过滤；历史采购同时保留供应商 |
| `demand` | is_direct、title、description_raw、published_at、action、urgency、trial_order_raw、recurring_quantity_raw、quantity_raw、frequency_raw、long_term_intent | 表达当前需求、时间、数量、频次和购买阶段 |
| `product` | terms、form、certification_or_grade_terms、packaging_raw、intended_use、temperature_constraint | 表达产品形态、等级/认证、包装、用途和储运条件 |
| `commercial` | amount_raw、price_or_quote_requested、moq_requested、sample_requested、incoterms | 表达价格、MOQ、样品和贸易条件 |
| `logistics` | destination_raw、lead_time_requested | 表达交付地点和交期要求 |
| `access` | contact_gate、channel_url | 联系入口与会员解锁边界，不把登录后字段伪装成公开字段 |
| `evidence/quality` | verification_status、snapshot_sha256、snapshot_path、observed_at、direct_demand_requires_corroboration、is_background_only | 来源审计、快照溯源、四维验真输入 |

## 4. 仍需保留但本轮缺失的字段

以下字段不能因为样本缺失而从正式 Schema 删除：

- 买家：`canonical_name`、法律实体名、官网域名、注册地址、注册号、母子公司关系；
- 需求：响应截止时间、预算及币种、正式数量单位、采购周期、目的港；
- 产品：品种、产地、粒度/目数、水分、农残/重金属/微生物限值、保质期；
- 准入：FDA、USDA Organic、HACCP、BRCGS、Kosher 等证书适用主体和有效期；
- 商务：付款方式、明确 MOQ、样品政策、价格区间；
- 联系：公司名、职位、企业邮箱/电话、采购入口验证时间；
- 验真：公司主体证据、需求原文证据、历史行为证据、时效证据的独立得分。

这些字段继续进入 `field_observation`，缺失时写 `null + UNKNOWN`，不填 0，不自动宣称符合。
