## A3 / A4 / A5：Python 权威 + Node fallback

A6 会话内刷新 A3/A4/A5 时，走 **capability CLI 桥** 调用 Free 的正式实现：

```
agent/skill-runtime/dependency-refresh.js  (runner，同步)
  → agent/skill-runtime/python-capability-runners.mjs  (execFileSync)
  → scripts/capability_cli.py  (stdin/stdout)
  → Free: timing_score / supply_demand_fit.evaluate / market_access_score
  → CapabilityResultEnvelope（domain_result.source = "python"）
```

- 注入点：`createLiveA2A6Runtime({ dependencyRunners })` → `createQianPulseSkillOrchestrator({ dependencyRunners })`（`server/index.js` boot 时探测 Python 可用性再注入）
- 任何失败（spawn / 非 0 / 坏 JSON / 超时）→ 自动回退 `agent/skill-runtime/a{3,4,5}.js`，标 `source = "node-fallback"`
- `QIANPULSE_PYTHON_CAPABILITIES=off` 强制用 Node；`PYTHON_BIN` 覆盖解释器
- `/api/health` 的 `python_capabilities: "on" | "off"` 反映当前状态
- 合同：`contracts/capability-result-envelope.schema.json`（两侧合同测试）
