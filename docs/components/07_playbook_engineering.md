# 07 Playbook Engineering

## 组件定位

商机经营复盘与知识沉淀中心。

目标：把每次 BD 任务转化为可复制经验。

## 能力边界

负责：
- 任务复盘
- 信号分析
- 渠道分析
- 话术分析
- 成交因素沉淀

不负责：
- 实时触达
- 对话执行

## 子模块

### Mission Review
分析任务结果。

### Signal Learning
识别高价值信号。

### Channel Learning
识别有效渠道。

### Playbook Generator
生成下一轮策略。

## 输入

Opportunity Outcome
Conversation History
Action Result

## 输出

BD Playbook
Strategy Recommendation
Skill Optimization

## API

GET /playbook
POST /playbook/generate

## 验收

- 可沉淀成功路径
- 可复用策略
- 可优化 Agent 行为
