# 买家猎手：机会决策驱动重构说明 V1.0

## 1. 产品核心

买家猎手是一套采购机会决策系统。它持续监控海外需求变化，把公开信号加工成企业今天值得追的采购机会。

核心问题不是“我们抓到了多少数据”，而是：

1. 谁值得追；
2. 为什么是现在；
3. 是否匹配当前卖方能力；
4. 市场是否可进入；
5. 有什么风险或缺口；
6. 今天应该采取什么动作。

## 2. 产品对象与加工链

```text
原始信号
→ 证据与实体
→ 采购需求
→ 采购窗口
→ 卖方能力匹配
→ 市场准入与风险
→ 机会优先级
→ 下一步动作
```

首页核心对象统一为 `OpportunityDecision`，默认输出“今日 Top 5”，而不是原始线索列表。

## 3. 评分与门禁

### 3.1 真实性是门槛

- `truth_score < 60`：不占用销售时间，直接 `PASS`；
- `truth_score >= 60`：进入机会判断；
- 真实性不再混入机会分，避免同一个事实被重复加权。

### 3.2 机会分

| 分项 | 权重 |
|---|---:|
| 采购时点 | 25 |
| 卖方匹配 | 25 |
| 买方强度 | 15 |
| 商业价值 | 15 |
| 市场准入 | 10 |
| 可执行性 | 10 |
| 风险扣分 | 最多 -30 |

### 3.3 决策状态

| 状态 | 含义 | 销售动作 |
|---|---|---|
| `PURSUE_NOW` | 值得立即追 | 今天进入执行队列 |
| `VERIFY_FIRST` | 有机会但存在关键未知 | 先补证或确认规格 |
| `WATCH` | 需求尚未形成或窗口偏弱 | 保持监控 |
| `PASS` | 真实性不足或硬条件失败 | 不投入销售时间 |

## 4. 付费逻辑

免费态可以查看：

- 买家公司名称；
- 采购需求摘要；
- 机会优先级与决策状态；
- “为什么现在”的摘要。

决策会员解锁：

- 完整供需匹配矩阵；
- 市场准入与风险判断；
- 证据时间线；
- 关键 Gap；
- 下一步行动方案。

`Lead Access` 独立作为执行层资源，消耗额度后提供公开采购入口和公开商务联系方式。联系方式不再是产品唯一付费理由。

## 5. 后端落地

- 决策引擎：`pipeline/opportunity_decision_engine_v1.py`
- 卖方能力样例：`pipeline/seller_capability_profile_demo_v1.json`
- 决策快照迁移：`db/migrations/002_opportunity_decision.sql`
- API 契约：`contracts/opportunity-decision-api-v1.yaml`
- 单元测试：`pipeline/test_opportunity_decision_engine_v1.py`

决策结果必须保存 `ruleset_version`、`input_snapshot_hash` 与排序位置，保证演示结果可复现、可解释、可审计。

## 6. 36 小时 Demo 边界

本轮只实现：预置卖方能力、确定性规则判断、每日 Top 5、会员决策权限、Lead Access 模拟额度与跟进状态。

本轮不实现：真实支付、自动外联、CRM、合同、交易、报关、物流、履约及在线学习模型。
