## 3. 新增 API 契约（agent:3317，均需 Bearer）

```
GET  /api/v1/collection-runs         → { config, runs }  runs 最新在前，上限 20
POST /api/v1/collection-runs         body {"sources":["b2b","alibaba","ted","ec21","ungm","samples","sam"]}
GET  /api/v1/collection-runs/:id     → 任务对象（含 steps/post_steps 逐步状态）
```

- `config`: `sources`（每源 `has_prior_run` 按 `pipeline/data_*` 目录判空）、`required_sources`、`sam_available`（`SAM_API_KEY`）、`full_run_required`（任一必需源无历史结果）。
- 必需源 = b2b/alibaba/ted/samples（对应 `aggregate_full_collection_v1.py` 硬依赖）。**本机首次采集必须全量**，否则 422 `COLLECTION_REQUIRES_FULL_RUN`（附 `missing_prior_dirs`）；跑过一次全量后可按单平台增量。
- 错误码：400 `INVALID_SOURCES` · 401 未登录 · 403 BUYER 角色 · 409 `COLLECTION_ALREADY_RUNNING`（单并发）· 422 见上。
- 任务状态机：`RUNNING → SUCCEEDED（pipeline 0 + export 0 + import 0 + reloadFree）| FAILED（非零/桥失败/超时）| INTERRUPTED（服务重启）`。
- 环境变量：`COLLECTION_PIPELINE_SCRIPT` / `COLLECTION_EXPORT_SCRIPT` / `COLLECTION_IMPORT_SCRIPT`（脚本路径覆盖，e2e 验证用）、`COLLECTION_RUN_TIMEOUT_MS`（默认 2h）、`PYTHON_BIN`。
