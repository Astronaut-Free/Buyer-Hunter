# 36 小时执行路径、排期与验收

## 1. 范围锁定

### P0 必须完成

1. 一个通用 `seller_capability_profile` 私有匹配模型，预置抹茶与蓝莓两组检索样例；不做商品展示。
2. 两个稳定公开来源连接器；一个可选来源。
3. 原始证据、清洗、实体去重、四维验真、规格匹配和机会评分。
4. 单 Orchestrator 串联 6 个固定 SKILL 合同，不拆微服务。
5. Buyer Signal API。
6. 4 屏前端主链 + 会员解锁弹层。
7. LIVE/CACHED/SAMPLE 三种数据模式与离线演示包。
8. 预置免费/会员两种账号；服务端完成需求预览、会员解锁、额度与 access grant，不接真实支付。

### P1 有余力再做

- 国家、时间、产品筛选。
- 实体人工复核小页面。
- 机会状态 `NEW → REVIEWED → FOLLOW_UP_STARTED`。

### 禁止临时加入

- 合同、支付、订单、物流、报关。
- 卖家店铺、商品上架、海外买家入驻、多卖家竞价、多角色权限、站内聊天。
- CRM、邮件自动发送、政府产业大屏。
- 第 4 个数据源或第 3 个产品专属流程。

## 2. 36 小时关键路径

| 时段 | 数据/后端负责人 | 其他角色依赖 | 验收点 |
|---|---|---|---|
| H0–H2 | 锁 Schema、样本 URL、来源规则、评分参数 | 产品锁 4 屏和 Demo 脚本 | JSON 样例可覆盖抹茶/蓝莓，接口合同冻结 |
| H2–H7 | 建库、证据模型、连接器 1/2、fixtures | Research 提供 10 条强弱标注样本 | 两源各抓到 ≥10 条或有合规公开样本；原文可回链 |
| H7–H11 | 清洗、日期/单位、字段抽取 | AI 负责人提供结构化抽取器 | 20 条 fixture 清洗可复现；UNKNOWN 不被补造 |
| H11–H15 | 实体去重、母子关系、审计 | Research 标注重复/母子公司对 | 同域别名合并；同名异国和母子公司不误合并 |
| H15–H19 | 四维验真、匹配、评分、Top 5 | 产品确认阈值与文案 | 边界测试通过；硬冲突不得入榜 |
| H19–H23 | 完成 API、OpenAPI、会员权限与解锁事务；提供前端 mock/真接口 | 前端接 4 屏和解锁弹层 | 未授权不返回受限字段；重复解锁不重复扣额度 |
| H23–H27 | 联调、证据详情、会员解锁、跟进/成交反馈 API | 前端完成交互 | 3 分钟主链无断点 |
| H27–H30 | 冻结 Demo 数据集、缓存与断网模式 | 全员按脚本走查 | 断网完整演示；明确标 CACHED |
| H30–H33 | 修 P0 Bug、性能与安全检查 | 产品准备一页作品说明 | 连续 5 次主链成功，P0 缺陷清零 |
| H33–H35 | 打包、README、启动脚本、备份视频 | 全员彩排 | 新机器按说明启动；视频仅作故障备份，不冒充实时 |
| H35–H36 | 提交材料、最终演练，不再加功能 | 队长提交 | 提前提交；仓库、链接、账号、步骤齐全 |

## 3. 数据准备的两条轨道

| 轨道 | 目的 | 规则 |
|---|---|---|
| Live | 证明连接器和真实数据链可运行 | 现场扫描 1–2 个稳定公开源；失败如实显示 |
| Frozen Demo Dataset | 保证演示稳定 | 比赛期间真实抓取并人工核验后冻结；保存 URL、时间、片段和快照哈希，标 `CACHED` |

`SAMPLE` 只用于边界测试或蓝莓配置展示，UI 必须明确标识，不能进入“真实买家 Top 5”叙事。

## 4. 开发任务拆解（数据/后端）

| Epic | 子任务 | 产物 | 验证 |
|---|---|---|---|
| E1 Schema | 买家需求模型、卖家私有匹配模型、迁移、种子数据 | DB schema + examples | 抹茶/蓝莓需求均通过校验，且无商品展示字段依赖 |
| E2 Connectors | discover/fetch/parse、限速、缓存 | 2 个连接器 | fixture + 小规模 live smoke |
| E3 Evidence | 快照哈希、文本片段、来源/时间 | evidence store | Top 5 每项有可回链证据 |
| E4 Normalize | 日期、单位、产品词、语言 | normalizer | 参数化单测 |
| E5 Entity | 别名、特征分、母子关系、审计 | entity resolver | 标注对 precision 优先 |
| E6 Extract | 规则 + LLM JSON、span 校验 | structured fields | 无 span 字段被拒绝 |
| E7 Truth | 四维分、硬门槛 | truth scorer | 边界用例全通过 |
| E8 Match | 三值矩阵、硬冲突、Gap | matcher | FAIL/UNKNOWN 行为正确 |
| E9 Rank | 分项评分、Penalty、Top 5 | opportunity scorer | 同输入同结果 |
| E10 API | Job、列表、详情、Buyer、对接状态 | FastAPI | OpenAPI/集成测试通过 |

| E12 Membership | 预置套餐/订阅、权限判断、解锁事务、成交反馈 | membership/access API | 非会员不泄露；重复解锁幂等 |

## 5. 风险排序与兜底

| 排名 | 风险 | 概率 | 影响 | 预防 | 现场兜底 |
|---:|---|---|---|---|---|
| 1 | 公开源反爬/超时 | 高 | 致命 | 静态页优先、限速、提前 smoke、固定缓存 | 切 CACHED，并展示上次抓取时间 |
| 2 | 抓到的不是采购需求 | 高 | 高 | 四维验真、人工标注强弱样本、弱信号不补位 | 只展示通过门槛的少量机会 |
| 3 | LLM 抽取幻觉 | 中 | 高 | span 必须来自原文、规则优先、低置信 UNKNOWN | 使用缓存抽取和规则结果 |
| 4 | 子公司误合并 | 中 | 高 | 强标识优先、阈值 0.92、母子只连关系 | 不确定时拆开而不是强合并 |
| 5 | 产品规格不可比 | 中 | 高 | 原值+标准值、三值匹配、产品形态必填 | UNKNOWN 显示为 Gap |
| 6 | 前后端合同漂移 | 中 | 中 | H2 冻结 OpenAPI 与 JSON fixture | 前端使用同一 fixture 降级 |
| 7 | 现场网络/模型不可用 | 高 | 高 | 冻结缓存、模型结果缓存、健康检查 | 全程离线 CACHED 模式 |
| 8 | 被误解成商品/交易平台 | 中 | 高 | 开场先讲角色关系；只演示海外需求聚合与卖家找买家 | 回到“今天最该联系哪 5 家” |
| 9 | 前端遮罩但接口泄露联系方式 | 中 | 致命 | 服务端字段级授权、接口测试、解锁事务 | 禁用受限接口，只演示已授权缓存账号 |

## 6. Go / No-Go 门禁

### H12 门禁

- 两个来源均有 fixture；至少一个可 live 抓取。
- Evidence 字段齐全。
- 若不满足：立即砍掉可选第 3 来源，不再寻找更多渠道。

### H24 门禁

- Top 5 API 返回真实结构，前端不再用自造字段。
- 四维验真和匹配矩阵可解释。
- 若不满足：砍 P1 筛选/复核页面，全员保主链。

### H30 门禁

- 断网可跑；主链连续 3 次成功。
- 若不满足：冻结所有功能开发，只修阻断问题。

### H34 门禁

- 提交包可在干净环境启动；作品说明和演示步骤完成。
- 之后禁止改 Schema、评分公式和依赖版本。

## 7. 最终验收清单

### 数据真实性

- [ ] Top 5 每个结论有 URL、发布时间/未知标记、抓取时间和原文片段。
- [ ] LIVE/CACHED/SAMPLE 无混淆。
- [ ] 历史贸易数据未被描述成近期 RFQ。
- [ ] 无 LLM 生成的虚构联系人、数量、认证或时间。

### 计算正确性

- [ ] 四维验真权重总和 100。
- [ ] Opportunity Score 权重总和 100，Penalty 单列。
- [ ] 59/60、74/75 等边界测试通过。
- [ ] 已证实硬冲突机会无法进入 Top 5。
- [ ] 相同输入和规则版本得到相同排序。

### 实体与规格

- [ ] 别名合并可追溯。
- [ ] 母子公司保持独立并展示关系。
- [ ] 抹茶与蓝莓只是两个配置样例，共用同一 API/页面/评分主链。
- [ ] PASS/FAIL/UNKNOWN 不被混用。
- [ ] 认证含有效期和适用范围，不只有布尔值。

### Demo

- [ ] 3 分钟主路径：搜索产品 → 扫描 → Top 5 预览 → 会员解锁 → 采购入口/公开联系方式 → 记录跟进。
- [ ] 非会员接口不返回完整买家名称、域名、采购入口或联系方式。
- [ ] 有效会员解锁成功；重复解锁不重复扣额度。
- [ ] 联系方式均有公开来源证据，不含私人信息或猜测值。
- [ ] 连续演示 5 次无 P0 错误。
- [ ] 断网模式可完整运行。
- [ ] 展位访客 30 秒内能理解“从噪声到 5 个机会”。

## 8. 3 分钟演示脚本

1. **20 秒：问题。** 贵州特色产品销售缺的不是公司名单，而是“谁此刻真有需求、我们能不能供”。
2. **20 秒：搜索条件。** 卖家输入“抹茶”，可选填写私有供货条件。
3. **30 秒：扫描。** 展示 40 条海外信号如何经过清洗、去重和四维验真。
4. **25 秒：Top 5 预览。** 免费态只显示受限摘要；解释分数不是成交概率。
5. **40 秒：详情。** 查看证据、Why Now、母子关系、匹配矩阵和 Gap。
6. **30 秒：会员解锁。** 切换预置会员，解锁采购入口和公开 B2B 联系方式，展示剩余额度变化。
7. **15 秒：撮合闭环。** 记录 `FOLLOW_UP_STARTED`，说明后续可回填 NEGOTIATING/WON/LOST。
8. **10 秒：收束。** 平台按会员制提供海外买家需求入口、验证信息和智能撮合，不是商品商城。
